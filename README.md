## Projects

### Maintained

| Project | What it is |
| --- | --- |
| [webclient-v3](https://github.com/scotCW/webclient-v3) | An independent, from-scratch browser client for RustDesk-compatible servers: encrypted remote control, file transfer and terminal, with sign-in through the account API. Unlicense. |
| [NUMIDENT-viewer](https://github.com/scotCW/NUMIDENT-viewer) | Native macOS app for searching the National Archives' public-use NUMIDENT files directly from their text files, with no import or database. |
| [MapGen](https://github.com/scotCW/MapGen) | Tauri desktop app for building printable hunting maps from public USGS, Census and USFS data, with multi-sheet PDF export, magnetic declination and land-access overlays. |
| [metal4Foam](https://github.com/scotCW/metal4Foam) | Metal-accelerated PCG/BiCGStab linear solver plugin for OpenFOAM on Apple Silicon. |
| [vgde](https://github.com/scotCW/vgde) | A self-hosted, browser-based voting party game with anonymous, at-your-own-pace voting. |

### Maintained forks

Forks of the self-hosted RustDesk server stack, with security, compatibility and English-language fixes:

- [rustdesk-server](https://github.com/scotCW/rustdesk-server): hbbs/hbbr with the server side of the secure TCP key exchange, so signed-in 1.5.x clients can connect.
- [rustdesk-api](https://github.com/scotCW/rustdesk-api): account and address-book API, with dependency security updates, an English codebase, and webclient-v3 built in.
- [rustdesk-api-web](https://github.com/scotCW/rustdesk-api-web): the admin UI for rustdesk-api, with merged community fixes and updated dependencies.
